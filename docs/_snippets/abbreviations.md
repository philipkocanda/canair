*[CAN]: Controller Area Network, the vehicle bus
*[DBC]: A file format that describes the signals in CAN frames
*[DID]: Data identifier, a 2-byte UDS identifier
*[DTC]: Diagnostic trouble code
*[ECU]: Electronic control unit
*[ELM327]: A text-command protocol for OBD adapters
*[ISO-TP]: ISO 15765-2, the transport layer that splits long messages over several CAN frames
*[KWP2000]: Keyword Protocol 2000 (ISO 14230), an older diagnostic protocol
*[LID]: Local identifier, a 1-byte KWP2000 identifier
*[NRC]: Negative response code, the reason an ECU refused a request
*[OBD-II]: On-Board Diagnostics, the standard vehicle diagnostic port and protocol
*[PCI]: Protocol control information, the ISO-TP framing byte or bytes
*[PID]: Parameter identifier, in canair a diagnostic request that returns a page of data
*[RID]: Routine identifier, a 2-byte UDS identifier
*[RTT]: Round-trip time
*[SID]: Service identifier, the first byte of a UDS or KWP2000 message
*[SLCAN]: Serial-line CAN, a text protocol for raw CAN frames
*[UDS]: Unified Diagnostic Services (ISO 14229), the modern diagnostic protocol
